# Notebooks da disciplina

Os notebooks foram preparados para execução no Google Colab, sem necessidade
de instalar Python localmente. Execute-os preferencialmente na ordem numérica e
execute as células em sequência, de cima para baixo.

O toolkit é instalado diretamente da branch `main`. Se a instalação for
atualizada durante a sessão, pode ser necessário reiniciar o ambiente de
execução e executar novamente todas as células.

## Orientações de uso

- Abra o notebook pelo badge **Abrir no Colab**.
- Faça uma cópia no Google Drive antes de editar.
- Execute as células de cima para baixo.
- Modifique os exemplos e exercícios livremente em sua cópia.
- Não substitua a célula de instalação por caminhos locais.
- Em caso de atualização do toolkit, reinicie o ambiente de execução e execute
  novamente todas as células.

Novos notebooks serão adicionados conforme os conteúdos da disciplina forem
desenvolvidos.
